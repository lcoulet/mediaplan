📱 Fonctionnalités principales

1. Plan Hebdo

  • Vue hebdomadaire des réservations
  • Filtres : médiateurs, offres, dates
  • Verrouillage : par défaut, cliquez sur le cadenas pour verrouiller/déverrouiller
  • Création de réservation : cliquez sur une case vide → sélectionnez un médiateur et une offre
  • Modification : cliquez sur une réservation existante
  • Suppression : cliquez sur une réservation → Supprimer

2. Plan Jour

  • Vue quotidienne des réservations avec les heures en colonnes (8h-19h)
  • Navigation : boutons ← → pour changer de jour, "Aujourd'hui" pour revenir à la date du jour
  • Voie "Réservations non affectées" (en haut) : créneaux importés non encore assignés à un médiateur
  • Voie "Médiateurs" : lignes avec les médiateurs actifs, chaque ligne affiche les créneaux assignés
    ✅ Bleu : médiateur confirmée pour l'offre
    📚 Jaune : médiateur en apprentissage
    ⚠️ Hachures : médiateur incompétent
  • Surlignage des compétences : Quand vous sélectionnez (clic ou glisser) un créneau, les médiateurs sont automatiquement surlignés selon leur compétence pour l'offre du créneau
  • Voie "Offres libres" (en bas) : catalogue des offres disponibles, glissables sur une ligne de médiateur + position horaire pour créer une réservation manuelle (disponible en permanence, verrouillé ou non)
  • Assignation depuis la modale : cliquez sur un créneau → ouvrez la modale → sélectionnez un ou plusieurs médiateurs via le multi-select. Les médiateurs sont triés par compétence : ✅ (confirmé) en premier, 📚 (apprentissage), ⚠️ (incompétent), puis par ordre alphabétique
  • Couleurs des médiateurs : pastille colorée à côté du nom de chaque médiateur
  • Mode modification : switch dans la barre d'outils (comme la vue hebdo)
    • Verrouillé (par défaut) : les créneaux importés ouvrent une modale d'assignation uniquement (médiateur-only). Les créneaux manuels restent entièrement modifiables. Les offres libres restent déplaçables pour créer des réservations manuelles.
    • Déverrouillé : tous les créneaux (importés et manuels) sont entièrement modifiables (offre, date, horaire, suppression). Les créneaux importés modifiés sont marqués "modifié après import".
    • Les créneaux (importés ou manuels) sont toujours déplaçables par glisser-déposer pour l'assignation à un médiateur, quel que soit l'état du verrouillage.

3. Médiateurs

  • Liste des médiateurs avec leurs couleurs
  • Ajouter / modifier / supprimer un médiateur
  • Compétences : Pour chaque médiateur, vous pouvez définir :
    • Compétences confirmées : offres que le médiateur peut animer seul
    • Compétences en apprentissage : offres que le médiateur est en train d'apprendre
  • Quand une offre passe de "en apprentissage" à "confirmée", le statut "en apprentissage" est automatiquement supprimé
  • Couleur : chaque médiateur a une couleur visible dans le planning et les réservations

4. Offres

  • Liste des offres de médiation (visites guidées, ateliers…)
  • Chaque offre a une couleur visible dans le planning et les réservations
  • Ajouter / modifier / supprimer une offre
  • Couleur : choisissez une couleur via le sélecteur dans le formulaire d'offre

5. Absences

  • Liste des absences (congés, missions, formations…)
  • Ajouter / modifier / supprimer une absence
  • Les absences sont affichées en gris sur le planning (non cliquables)

6. Import / Export

  • Export JSON : sauvegarde complète de toutes les données (médiateurs, offres, créneaux, absences, compétences) au format JSON.gz (compressé)
  • Export Excel : export du planning ou de la liste des médiateurs
  • Import JSON : restauration depuis un fichier JSON ou JSON.gz. ⚠️ Attention : l'import remplace toutes les données actuelles
  • Reset : 🔄 → réinitialise avec les données de démonstration

7. Gestion des compétences

  • Statuts des compétences :
    • ✅ Confirmée : le médiateur peut animer l'offre seul
    • 📚 En apprentissage : le médiateur est en formation sur cette offre
    • ⚠️ Incompétent : le médiateur ne connaît pas cette offre
  • Règles automatiques :
    • Si un médiateur a une compétence "confirmée" pour une offre, le statut "en apprentissage" est automatiquement supprimé
    • Si une offre est supprimée, toutes les références à cette offre dans les compétences des médiateurs sont automatiquement supprimées
  • Assignation avec avertissement : Quand vous essayez d'assigner un médiateur incompétent à une offre, un avertissement ⚠️ est affiché dans le sélecteur de médiateurs
  • Surlignage dans le Plan Jour : Quand vous sélectionnez un créneau pour le déplacer, les médiateurs sont surlignés selon leur compétence pour l'offre du créneau

8. Raccourcis clavier

  • Ctrl+Z : Annuler
  • Ctrl+Shift+Z : Rétablir

🎨 Couleurs

  • Médiateurs : chaque médiateur a une couleur unique (visible dans les pills)
  • Offres : chaque offre a une couleur unique (visible dans les pills)
  • Absences : affichées en gris

🔧 Administration

  • Verrouillage : le planning est verrouillé par défaut. Déverrouillez pour modifier.
  • Réservations modifiées après import : marquées comme modifiées
  • Recouvrement : les réservations qui se chevauchent sont affichées côte à côte

📌 Bonnes pratiques

  • Sauvegardez régulièrement via Import/Export JSON
  • Vérifiez les conflits avant d'assigner un médiateur à une réservation
  • Utilisez les couleurs pour repérer rapidement les médiateurs/offres
  • Gérez les compétences : maintenez à jour les compétences des médiateurs pour éviter les assignations incompétentes
