Les réglages enregistrés bornent les demi-journées de la vue quotidienne et de la valorisation.

En-tête : l'entrée « Import / Export » est remplacée par « Configuration » ; le bouton « Import Secutix » vit dans l'en-tête à côté des actions, visible depuis toutes les vues — il n'apparaît dans aucune section de cette vue.
Espaces : le blanc (Crypte, « auto Secutix ») est réservé aux espaces auto-créés par l'import Secutix ; la palette de migration n'attribue jamais de blanc. La suppression d'un espace référencé par une offre ou un créneau est refusée.

Supprimer toutes les données ?

Cette action supprime définitivement les réservations, absences et plannings locaux. Sauvegardez vos données au format JSON.gz avant de continuer. Cette action est irréversible.
