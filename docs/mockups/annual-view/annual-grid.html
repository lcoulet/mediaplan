WE, amgt JJ/MM, événements) Rouge + code = absence liée au travail (grève, syndicat, formation) Blanc = neutre (jour non travaillé ou médiateur sans cycle) Hachures = musée fermé (25/12, 01/01, 01/05) — édition en alerte non bloquante Fond ambre = jour férié (liste française par défaut, modifiable par dérogation et par année) S1Pilule de semaine de cycle (S1, S2…) — affichée une fois par semaine ISO, sur la cellule du lundi, valable pour toute la semaine ×NCompteur de samedis travaillés (calculé, alimente la valorisation à partir du seuil — vert : samedi valorisé) reliquat/déficitSolde trimestriel (médiateurs avec aménagement) Abréviations dans les cellules — le survol (title) affiche le texte complet (FORM = formation, SYND = syndicat, etc.)

Aucun médiateur avec cycle, aucune absence saisie. Les jours et les semaines ISO restent calculés pour l'année sélectionnée.

Structure : lignes = tous les jours (week-ends compris), colonnes = médiateurs, une cellule par demi-journée (Matin · Après-midi). Semaine ISO « S 40 » sur la ligne du lundi uniquement ; 2026 compte 53 semaines ISO (« S 53 » le lundi 28/12). Maquette : extrait d'une semaine + jours remarquables, pas les 365 jours.
Présence dérivée : l'orange vide est CALCULÉ depuis le cycle (jamais stocké) ; effacer une cellule revient à l'état dérivé. Bob (sans cycle) : cellules neutres, aucune pilule de cycle. La semaine de cycle (S1, S2…) est affichée une fois par semaine ISO, dans la zone de la cellule du lundi, valable pour toute la semaine.
Compteur de samedis : calculé automatiquement (samedis de l'année avec créneaux), affiché sur les lignes de samedi, remis à zéro chaque année ; il alimente le seuil des samedis valorisés (ex. ×10 vert = 10e samedi valorisé, valuedSaturdayThreshold). Aucune colonne de comptage (ratio, totaux) — décision du 2026-10-03.
Solde trimestriel : badge « reliquat / déficit » pour les médiateurs avec un aménagement (Karim, temps partiel) ; aucun solde pour les autres. Fériés : liste française par défaut, modifiable par dérogation et par année (voir la maquette d'édition). Export Excel au format exact de la table de référence ; pas d'impression/PDF en v1.
Contrastes (WCAG 1.4.3 / 1.4.11) : jaune #F9A825/#2b2b2b = 7,18 ; orange mission #d68c45/#3a2408 = 5,36 ; gris #6b6b6b/blanc = 5,33 ; rouge #c0392b/blanc = 5,44 ; badges #e3efe8/#1e5536 = 7,38 et #fdecea/#c0392b = 4,76 ; alerte ambre #fef5e7/#8a4d10 = 6,17 ; orange dérivée #C67A33/blanc = 3,37 (1.4.11 vs cellule neutre) ; hachures #8a8a8a/#f5f5f5 = 3,17 (1.4.11).
