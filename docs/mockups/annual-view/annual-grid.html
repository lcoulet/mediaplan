Légende (couleurs et codes)
Orange vide = présence dérivée du cycle (calculée, jamais stockée) Jaune + code = absence (CA, RHS, RTT, AM, CET, CEX, TPT, congé parental / maternité / naissance, dispo) Rose + TELE = télétravail Violet + amgt JJ/MM = aménagement d'un jour travaillé (exception au cycle) Bleu + code = souhait en attente (CA, RHS, RTT — demande non confirmée, distinct du congé posé en jaune) Orange + texte = mission / événement (Réf. WE, stop motion, offre anniv, privatisation) Vert + JDM = mission aux Jardins du muséum (mission, pas une absence) Rouge + code = absence liée au travail (grève, syndicat, formation) Blanc = neutre (jour non travaillé ou médiateur sans cycle) Hachures = musée fermé (25/12, 01/01, 01/05) — édition en alerte non bloquante Fond ambre = jour férié (liste française par défaut, modifiable par dérogation et par année) S1Pilule de semaine de cycle (S1, S2…) — affichée une fois par semaine ISO, sur la cellule du lundi, valable pour toute la semaine ×NCompteur de samedis travaillés (calculé, alimente la valorisation à partir du seuil — vert : samedi valorisé) reliquat/déficitSolde trimestriel (médiateurs avec aménagement) Abréviations dans les cellules — le survol (title) affiche le texte complet (FORM = formation, SYND = syndicat, etc.)

Structure : lignes = tous les jours (week-ends compris), colonnes = médiateurs, une cellule par demi-journée (Matin · Après-midi). Le numéro de semaine ISO vit dans sa PROPRE colonne « Sem. » à gauche, à cheval sur les 7 lignes de la semaine (comme le fichier Excel de référence — décision 2026-10-04) ; 2026 compte 53 semaines ISO (« S 53 » la semaine du lundi 28/12). Maquette : extrait d'une semaine + jours remarquables, pas les 365 jours.
Navigation (décision 2026-10-04) : la vue suit la date globale de la route (?date=…) — la ligne du mer. 30/09 est ici la ligne ciblée (surlignage + défilement, pastille ●). Un clic sur un libellé de semaine (« S 40 ») ouvre la vue hebdo sur cette semaine ; un clic sur le libellé d'une date ouvre la vue jour sur cette date (maquette : le clic est journalisé, pas de vrai routeur). Boutons focalisables au clavier (Tab).
Présence dérivée : l'orange vide est CALCULÉ depuis le cycle (jamais stocké) ; effacer une cellule revient à l'état dérivé. Bob (sans cycle) : cellules neutres, aucune pilule de cycle. La semaine de cycle (S1, S2…) est affichée une fois par semaine ISO, dans la zone de la cellule du lundi, valable pour toute la semaine.
Compteur de samedis : calculé automatiquement (samedis de l'année avec créneaux), affiché sur les lignes de samedi, remis à zéro chaque année ; il alimente le seuil des samedis valorisés (ex. ×10 vert = 10e samedi valorisé, valuedSaturdayThreshold). Aucune colonne de comptage (ratio, totaux) — décision du 2026-10-03.
Solde trimestriel : badge « reliquat / déficit » pour les médiateurs avec un aménagement (Karim, temps partiel) ; aucun solde pour les autres. Fériés : liste française par défaut, modifiable par dérogation et par année (voir la maquette d'édition). Export Excel au format exact de la table de référence ; pas d'impression/PDF en v1.
Médiateurs désactivés (décision 2026-10-04) : case à cocher « Médiateurs désactivés » dans la barre d'outils (label + input focalisables, état coché visible) ; les colonnes des médiateurs désactivés (Mediator.active === false — ex. Sofia Martin) sont MASQUÉES PAR DÉFAUT et révélées par la case.
