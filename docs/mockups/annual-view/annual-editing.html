⚠ Le musée est fermé ce jour-là. L'édition reste possible — exceptions légitimes (décision du 2026-10-03, diffère du refus de la vue quotidienne).
Structure (2026-10-04) : le numéro de semaine ISO vit dans sa PROPRE colonne « Sem. » à gauche (à cheval sur les 7 lignes de la semaine, comme le fichier Excel de référence), collée à la colonne date ; la navigation (semaine → vue hebdo, jour → vue jour, synchro route) est spécifiée dans annual-grid.feature / annual-grid.html.
(1) Menu contextuel : un clic sur une cellule de demi-journée ouvre le menu — tous les codes (CA, RHS, AM, TELE, amgt, Souhait, Réf. WE, CEX, TPT), texte libre avec codes décodés en suggestions (« Stop Motion » s'afficherait en orange de mission), « Effacer (retour au dérivé) » rétablit la présence dérivée, « Peindre ce code » active le mode peinture. « Souhait » (demande de congé en attente — type leave_request) s'affiche en BLEU dans la cellule, distinct du congé confirmé en jaune ; l'aménagement « amgt JJ/MM » s'affiche en VIOLET ; JDM (mission Jardins du muséum) est proposé dans les suggestions du texte libre et s'affiche en VERT. Items focalisables (Tab / Maj+Tab), Échap ferme le menu (ou un clic hors du menu). Abréviations dans les cellules — le survol (title) affiche le texte complet.
(2) Mode peinture : bannière « Peinture : CA — cliquez les cellules à remplir, Échap pour quitter » ; curseur pinceau sur les cellules, menu contextuel désactivé. Chaque clic peint UNE cellule, sans glisser-déposer ; le 09/06 et le 10/06 matins + après-midi d'Alice sont peints CA. Peindre fonctionne aussi sur les autres médiateurs (Bob sans cycle inclus) ; chaque cellule peinte = UNE opération annulable. Un clic hors de la grille quitte aussi le mode peinture.
(3) Jour de fermeture : alerte ambre NON BLOQUANTE « Le musée est fermé ce jour-là » dans le menu (25/12, 01/01, 01/05) — la saisie reste possible.
(4) Fériés : panneau « Fériés 2026 » — liste française par défaut en puces ; + Ajouter une date (ex. 10/08), ✕ retire (ex. 14 juillet barré), dérogations propres à l'année sélectionnée.
(5) Annuler / rétablir : ↶ actif après chaque saisie ou cellule peinte (une opération par cellule), ↷ rétablit ; le changement d'année ne touche jamais les données des autres années (absences stockées par date et par demi-journée).
